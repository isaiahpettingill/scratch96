# Editor

Editor code belongs here.

Use Carbon Web Components for non-Blockly UI. Blockly owns the block workspace; Carbon owns the surrounding IDE controls, panels, forms, tabs, modals, and navigation.

Planned areas:

- Blockly block definitions.
- Blockly serialization into project JSON.
- General settings page.
- Sprite editor panel.
- Audio editor panel.
- Cartridge info panel.
- Console and diagnostics panel.
